# Story Brief: STORY-011 Bun Pet

Business intent: gamified daily-engagement hook backed by a dedicated
backend module — distinguishes this from the more utilitarian vibes/reminder
features in the same epic.

Primary persona: paired couple, both partners, shared pet state.

Backend contract: `pets` module, frozen (A1).

Success signal: both partners see the same pet state and any interaction is
backed by a real API capability, not client-only decoration.
