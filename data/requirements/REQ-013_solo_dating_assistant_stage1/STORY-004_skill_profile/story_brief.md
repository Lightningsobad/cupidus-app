# Story Brief: STORY-004 Skill Profile ("Phiên Bản Tôi")

- Actor: solo user declaring their own skills.
- Capability: a broadly-defined, editable, deletable self-declared skill
  list (SB-197), deliberately worded to avoid "I have none" dead-ends.
- Business value: unlocks the entire handmade-gift branch (STORY-011) and
  teach-your-skill activities (STORY-022) — flagged as the highest
  implementation-risk foundation item (brainstorm: ~80% "no skills" risk if
  worded like a CV).
- Key business rules: no scoring/ranking of skills (rule 1(f)); deletable
  (XD4).
- Key edge/failure case: a user with no obvious craft skill must still be
  able to record something via broad example prompts.
- Existing system entry/discoverability seed: new screen; entry point set by
  UI/UX Designer, likely onboarding/profile.
- Direct AC/OQ anchors: AC1-4 in `story_master.md`; no story-level OQs.
- Complexity and why: standard — new data object and screen, no matrix logic
  yet (that's STORY-011). Lane: shared.
- Dependencies: NONE.
